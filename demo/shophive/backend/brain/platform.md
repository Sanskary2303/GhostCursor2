# ShopHive Platform Overview

GHOST_BRAIN_SERVER_ONLY_CANARY_2026

ShopHive is a modern footwear and sportswear store. All currency is in USD ($).
Free shipping applies automatically on orders over $75.
Standard return policy is 30 days from delivery.
Available system themes: "light" and "dark".

## Navigation Map
- Home ("/") displays the product catalog grid.
- Product Detail ("/product/:id") provides sizes, pricing, and add-to-cart.
- Cart ("/cart") shows selected items, quantities, promo codes, and checkout button.
- Checkout ("/checkout") provides multi-step shipping address and payment confirmation.
- Orders ("/orders") provides shipment tracking and returns walkthrough.
- Settings ("/settings") provides light/dark mode appearance toggle and notification preferences.

## Business Policies & Rules
- Sales tax rate: 8.25% (applied automatically at checkout).
- Promo code "SAVE20" grants 20% off on subtotal of $100 or higher.
- Promo code "FREESHIP" waives standard $5.99 shipping on any cart size.
- Standard return policy is 30 days from delivery with prepaid return labels.
- Maximum quantity per order item is 5 pairs.
