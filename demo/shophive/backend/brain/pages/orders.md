# Orders Page Context

- Displays user's order history and shipment tracking.
- Order statuses: Pending, Processing, Shipped, Delivered, Returned.
- Each order has a timeline showing progress events and timestamps.
- Interactive link to real-time tracking: `orders.tracking_link`.
- Order cards have IDs: `orders.item.{id}` (e.g. `orders.item.SH-1024`).
- Return Policy Walkthrough: Returns are initiated from the orders page within 30 days of delivery.
