# Settings Page Context

- Appearance: Supports switching between Light and Dark mode via the theme toggle switch.
- To switch to dark mode, the co-pilot animates to and toggles the switch if state is currently light.
- Target ID for the theme toggle: `settings.theme_toggle`.
- Notifications: Email alerts are enabled by default. Users can toggle SMS and Push notifications.
  - Target IDs: `settings.notif_email`, `settings.notif_sms`, `settings.notif_push`.
- Shipping Address: Displays default saved address (`settings.saved_address`).
