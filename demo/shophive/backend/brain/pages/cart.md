# Cart Page Context

- Lists selected sneakers with chosen sizes and quantities.
- Promo code input: `cart.promo_code` with button `cart.apply_promo`.
  - "SAVE20": 20% off subtotal when subtotal >= $100.
  - "FREESHIP": free shipping on any subtotal.
- Checkout button: `cart.checkout_btn` (navigates to `/checkout`).
- Individual cart items: `cart.item.{id}`.
